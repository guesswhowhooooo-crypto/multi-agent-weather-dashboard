
# 🌏 City Weather Dashboard HMI (Agent-style Programming) – Current Hour Version

เวอร์ชันนี้ปรับปรุงให้ **แสดงข้อมูลย้อนหลังจนถึงปัจจุบันเท่านั้น** ตามที่ผู้ใช้ต้องการ:
- ค่าที่ใช้ใน Dashboard จะอ้างอิงจาก **ชั่วโมงล่าสุดที่ไม่เกินเวลาปัจจุบัน (Current Hour)**
- กราฟจะแสดง **ข้อมูลย้อนหลัง (Historical) ตามจำนวนชั่วโมงที่เลือก** จนถึงปัจจุบัน
- ตัดข้อมูลคาดการณ์ล่วงหน้า (Forecast ในอนาคต) ออก ไม่ใช้ในการแสดงผล

ข้อมูลทั้งหมดมาจาก **Open-Meteo Public API** ซึ่งให้ข้อมูลในระดับ **รายชั่วโมง (Hourly)**

## ฟีเจอร์สำคัญในเวอร์ชันนี้

1. แสดงเวลา Refresh ของ Dashboard ชัดเจน (เวลาปัจจุบันของเครื่องผู้ใช้)
2. ค่าล่าสุด (Latest Measurements) คือชั่วโมงล่าสุดที่ไม่เกินเวลาปัจจุบัน
3. กราฟ Time-series แสดงข้อมูลย้อนหลังจากอดีตจนถึงชั่วโมงปัจจุบัน (ไม่รวมอนาคต)
4. Raw Data Table มีคำอธิบายว่าคอลัมน์แต่ละตัวคืออะไร และแสดงเฉพาะข้อมูลย้อนหลังจนถึงปัจจุบัน
5. ปุ่ม Export CSV จะดาวน์โหลดข้อมูลย้อนหลังจนถึงเวลาปัจจุบัน (ไม่รวม forecast)

วิธีติดตั้งและการรันเหมือนเดิม:
- `pip install -r requirements.txt`
- `streamlit run app.py`
